# Contributing to Redstart

Contributions are welcome. Before you open a pull request, here's what to know.

## Licensing

Redstart is licensed under the
[GNU Affero General Public License, version 3](LICENSE) (`AGPL-3.0-only`).
Releases up to and including `1.0.0-alpha.12` were published under the MIT
License, and those releases stay under MIT.

The project is also offered under separate commercial licenses. To keep that
possible, every contributor signs the
[Contributor License Agreement](CLA.md) once, before their first pull request
is merged. You keep the copyright in your work. Section 6 of the agreement
promises your contribution stays available under an open-source license.

To sign, put the line from [How to sign](CLA.md#how-to-sign) in your first pull
request's description. The pull request template includes it.

## The name and the mascot

The name "Redstart" and the mascot artwork aren't covered by the code license.
If you publish a fork, see [TRADEMARKS.md](TRADEMARKS.md): a distributed
modified version needs its own name and its own mascot.

## Third-party code

If your change brings in code from another project, or adds a new dependency,
say so in the pull request and give its license. Third-party code has to be
under a license compatible with AGPL-3.0. Most permissive licenses (MIT, BSD,
Apache-2.0, ISC) are fine. Its notice also goes in
[THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md).
